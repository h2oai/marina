# Memory workflows

`run.ts` captures a source, retrieves cited evidence, records a task, compares a recipe offline,
changes a premise, resumes with a fresh client and records completion, in disposable spaces.

Run (after `bun run memory init … --credentials data/workflow-demo.json` and `bun run memory serve`):
`bun examples/memory-workflows/run.ts data/workflow-demo.json`

Guide: [Put memory to work](../../docs/guides/memory-workflows.md#try-a-complete-working-example).
