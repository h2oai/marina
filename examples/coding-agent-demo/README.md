# Coding Agent Demo

This intentionally broken TypeScript project accompanies the
[coding-agent walkthrough](../../docs/guides/coding.md#first-autonomous-fix-copy-and-paste).
Copy it to a disposable directory before giving it to Marina. The task is to repair percentage
discount arithmetic, validate inputs, add regression coverage, and leave both tests and typecheck
passing.

The initial test failure is deliberate. Do not fix the fixture in this directory; it is the stable
starting state for each walkthrough.
