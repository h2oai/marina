# Code of Conduct

Marina adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The canonical text and translations are maintained at that URL.

## Scope

This Code applies to all project spaces — the repository, issue tracker, pull requests, discussions, and any other forum where someone is acting on behalf of, or interacting about, Marina.

## Reporting

If you experience or witness behavior that violates the Code, please report it via one of:

1. GitHub's private "Report content" link on the offending comment or PR, or
2. A private security advisory on this repository (see [SECURITY.md](SECURITY.md) for the mechanics — the same flow handles conduct reports), or
3. Direct message to a project maintainer.

Maintainers will respond within a reasonable timeframe, keep reports confidential, and follow the enforcement guidelines linked above.

## Enforcement

Maintainers may warn, temporarily restrict, or permanently remove participants whose behavior is incompatible with this Code. The four-tier enforcement ladder from the Contributor Covenant applies: correction → warning → temporary ban → permanent ban.
