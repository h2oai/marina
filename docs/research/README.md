# Research (local only)

This directory is gitignored apart from this file. Research, plans, strategy, internal audits and
qualification reports belong in the private `marina-internal` repository, not in the public tree.

Looking for memory documentation? Start with the
[standalone memory service guide](../guides/memory-service.md) for setup, HTTP contracts, portable
sources, review, caching, federation, backups and reproducible checks. The
[symbolic interfaces guide](../guides/memory-interfaces.md) covers TypeScript, Python, MCP,
coding-agent skills, resident access and human commands. The [world memory guide](../guides/memory.md)
covers notes, recall, core memory, reflection and shared pools.
